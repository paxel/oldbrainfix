# Changelog

All notable changes to Old Brain Fix are documented in this file.
Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versioning: [SemVer](https://semver.org/).

## [0.7.0]

### Added

- A Routine or Reminder can give heads-ups before it is due, such as "Dentist in 20 min", silent in Quiet Hours and each person's own. ([obf-1046](https://github.com/paxel/oldbrainfix/issues/356))
- "Quiet today" in the Agenda's menu keeps today quiet on your Devices: everything still shows, nothing rings, and what is left undone counts as skipped. ([obf-1044](https://github.com/paxel/oldbrainfix/issues/354))
- A Note shows "Linked from" at its end, listing the Notes whose app links lead to it. ([obf-1035](https://github.com/paxel/oldbrainfix/issues/345))
- Import also takes AsciiDoc, Org, reStructuredText and HTML files, each as a formatted Note, without running anything in them. ([obf-1038](https://github.com/paxel/oldbrainfix/issues/348))
- Code is coloured by its language: a Code text by the one picked beside "Code", a code block by the one its first line names. ([obf-1036](https://github.com/paxel/oldbrainfix/issues/346))
- "Add grammar…" in Settings colours code in more languages from a Sublime syntax file, on all your Devices and only for you. ([obf-1037](https://github.com/paxel/oldbrainfix/issues/347))
- Tips explain each screen on a first visit and each new thing once; new people get them instead of the Quick start Help Notes. ([obf-1043](https://github.com/paxel/oldbrainfix/issues/353))

### Changed

- On the phone the search field of the Areas list, an Area and a Topic sits on a band set off from the page. ([obf-1041](https://github.com/paxel/oldbrainfix/issues/351))
- One "Remind me…" sets up a Routine or a Reminder wherever "Routine…" and "Reminder…" were offered apart. ([obf-1034](https://github.com/paxel/oldbrainfix/issues/344))
- The quick note shows only the text, three Nudge buttons and More, with everything else in the Note editor and the Note dialog. ([obf-1042](https://github.com/paxel/oldbrainfix/issues/352))
- In Quiet Hours a Routine or Reminder shows without sound or vibration, unless its Escalation is on. ([obf-1045](https://github.com/paxel/oldbrainfix/issues/355))

### Fixed

- On macOS a click on a notification brings up the window on what it is about. ([obf-1039](https://github.com/paxel/oldbrainfix/issues/349))
- On Android a tap on the Catch-up Notification shows the Agenda from any page. ([obf-1039](https://github.com/paxel/oldbrainfix/issues/349))
- A voice recording no longer stops when the phone locks, and the screen stays on while it records. ([obf-1040](https://github.com/paxel/oldbrainfix/issues/350))
