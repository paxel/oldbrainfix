# Architecture decisions

Each file here records one decision of Old Brain Fix: what was decided, the options considered and the consequences. Files are numbered in the order the decisions were made, `NNNN-title.md`. A later change to a decision is added to its file as a section ("Amended by #n"); a decision that replaces another names it at its top ("Supersedes ADR 0031"). The terms are those of [CONTEXT.md](../../CONTEXT.md).

#n refers to issue n on https://github.com/paxel/oldbrainfix/issues.
