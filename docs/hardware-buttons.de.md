# Erfassen mit einer Hardware-Taste

Old Brain Fix bietet drei Erfassungsseiten, die direkt öffnen, ohne etwas
dazwischen: **Sprachnotiz**, **Textnotiz** und **Fotonotiz**. Du erreichst
sie

- als **App-Verknüpfungen**: lange auf das Symbol von Old Brain Fix tippen,
- als **Schnelleinstellungs-Kacheln**: im Benachrichtigungsbereich die
  Kacheln bearbeiten und „Sprachnotiz“, „Textnotiz“ oder „Fotonotiz“
  hinzufügen,
- als **Widgets auf dem Startbildschirm**: ein Knopf je Art, oder alle drei
  nebeneinander,
- als **Aktivitäten**, die andere Apps starten können: „Sprachnotiz“,
  „Textnotiz“ und „Fotonotiz“ unter Old Brain Fix.

Eine Taste oder Geste des Handys kann jede davon starten. Was ein Handy
anbietet, hängt von Marke, Modell und Android-Version ab; die Menüs unten
liegen auf vielen Modellen dort, nicht auf allen. Die Menünamen können auf
deinem Handy abweichen.

## Wenn das Handy gesperrt ist

Die Erfassungsseiten gehören zur App, und deren Notizen bleiben hinter der
Sperre des Handys: Eine Erfassungsseite erscheint erst, wenn das Handy
entsperrt ist. Eine Kachel, auf dem Sperrbildschirm angetippt, fragt sofort
nach dem Entsperren und öffnet dann die Erfassungsseite. Die eigene
App-Sperre von Old Brain Fix steht nie vor dem Erfassen.

## Samsung

Auf vielen Samsung-Modellen lässt **Einstellungen › Erweiterte Funktionen ›
Seitentaste** zweimal Drücken der Seitentaste eine App deiner Wahl öffnen.
Dort gewählt, öffnet Old Brain Fix auf seinem Startbildschirm, nicht auf
einer Erfassungsseite. Um direkt auf einer Erfassungsseite zu landen, nimm
eine Tastenbelegungs-App (siehe unten) mit einer der Verknüpfungen.

## Motorola

Auf vielen Motorola-Modellen hat die **Moto**-App (oder **Einstellungen ›
Gesten**) Gesten wie zweimal auf die Rückseite tippen, die eine App öffnen
können. Bietet die Geste App-Verknüpfungen an, wähle „Sprachnotiz“,
„Textnotiz“ oder „Fotonotiz“; sonst nimm eine Tastenbelegungs-App.

## Xiaomi, Redmi, POCO

Auf vielen Modellen kann **Einstellungen › Weitere Einstellungen ›
Gestenverknüpfungen** (auf manchen Modellen ein Tippen auf die Rückseite)
eine App starten. Bietet es App-Verknüpfungen an, wähle eine von Old Brain
Fix; sonst nimm eine Tastenbelegungs-App.

## Nothing

Auf vielen Nothing-Modellen mit der Essential-Taste ist diese Taste
Nothings eigenen Funktionen vorbehalten. Nimm stattdessen die Kacheln, die Widgets oder die
Verknüpfungen, oder eine Tastenbelegungs-App für eine andere Taste, etwa
eine Lautstärketaste.

## Google Pixel

Pixel-Handys haben dafür keine eigene Taste. Lege eine Kachel in den
Schnelleinstellungen oder ein Widget dorthin, wo du am schnellsten
hinkommst, oder tippe lange auf das App-Symbol für die Verknüpfungen. Auf
vielen Pixel-Modellen kann **Einstellungen › System › Gesten › Quick Tap**
(zweimal auf die Rückseite tippen) eine App öffnen; damit öffnet Old Brain
Fix auf seinem Startbildschirm.

## Jedes Handy: eine Tastenbelegungs-App

Tastenbelegungs-Apps aus dem App-Store können einen Tastendruck (zum Beispiel
lange auf eine Lautstärketaste) mit einer Aktion belegen. Bei vielen davon
kann die Aktion eine App-Verknüpfung oder eine Aktivität einer App sein:
wähle „Sprachnotiz“, „Textnotiz“ oder „Fotonotiz“ von Old Brain Fix. Solche
Apps brauchen meist Androids Bedienungshilfen-Zugriff, um Tastendrücke zu
sehen; diesen Zugriff bekommt die Tastenbelegungs-App, nicht Old Brain Fix.
