Der Text einer Notiz kann formatiert sein, Code sein und Tabellen, Statuskästchen und #Wörter enthalten. Sprachaufnahmen bekommen ein Transkript und Fotos einen Fototext, beides auf dem Gerät erzeugt; die Suche findet Notizen an all dem. Jeder Kasten unten zeigt die Schritte auf dem Handy und auf dem Desktop.

Die Desktop-App macht dasselbe mit Maus und Tastatur. Eine Notiz öffnet mit einem Doppelklick auf ihre Karte im Notiz-Dialog; die Formatleiste sitzt über dem Textfeld; in einer Tabelle im Text gehen Tab und Umschalt+Tab zur nächsten und zur vorigen Zelle; und das Suchfeld sitzt über der Liste der Notizen. Die Details jedes Kastens sagen, wo der Desktop anders ist.

Den Text einer Notiz formatieren

Mach Wörter fett, kursiv oder zur Überschrift, oder mach eine Liste, ein Zitat, einen Link oder Code.

  • Drücke lange auf die Karte der Notiz.
  • Wähle die Wörter aus, die du formatieren willst.
  • Tippe Fett oder eine andere Taste der Formatleiste.
  • Tippe Zurück.
    •
  • Doppelklicke die Karte der Notiz.
  • Klicke in den Text.
  • Wähle die Wörter aus, die du formatieren willst.
  • Klicke Fett oder eine andere Taste über dem Text.
  • Klicke neben den Text.
    •

    Der Text einer Notiz und eines Abschnitts kann fett, kursiv oder durchgestrichen sein, zwei Überschriftenebenen haben, Aufzählungen und nummerierte Listen mit einer Einrückungsebene, Zitate, Links, Code im Text, Codeblöcke und Tabellen. Er wird als Markdown gespeichert, genau so, wie er geschrieben ist. Ein Text bleibt unformatiert, bis er zum ersten Mal formatiert wird: durch eine Taste der Formatleiste, durch ein als Markdown getipptes Format, durch Einfügen eines Texts, der eines verwendet, oder durch Formatierter Text in seiner Plakette Textformat. Ein formatierter Text wird nicht direkt wieder unformatiert; er kann Code werden, und Code kann unformatiert werden (siehe „Ein Skript als Code behalten“). Karten, Abschnitte, gesendete Notizen und Sicherungen zeigen ihn formatiert. Ein Gerät mit Old Brain Fix 0.1 zeigt das Markdown und kann es nicht ändern.

    Die Formatleiste.

    Die Formatleiste gibt es in Erweitert. In Einfach hat ein Feld keine, während getipptes Markdown weiter formatiert und ein formatierter Text formatiert erscheint.

    Auf dem Handy sitzt die Formatleiste auf der Tastatur, solange der Notiz-Editor oder Zur Notiz hinzufügen sie geöffnet hat, und die Schnellnotiz, wo die Einstellungen unter „Schnellnotiz“ Formatleiste einschalten, ein Schalter, der in Erweitert erscheint und zu Beginn aus ist. Ihre Tasten, in dieser Reihenfolge:

    • ☐: ☐ einfügen am Cursor (im Notiz-Editor und in einer Tabellenzelle; nicht in Zur Notiz hinzufügen und der Schnellnotiz; siehe „Ein Statuskästchen im Text abhaken“).
    • Fett, Kursiv und Durchstreichen.
    • H1 und H2: Große Überschrift und Kleine Überschrift.
    • Aufzählung, Nummerierte Liste und Zitat.
    • Link, Link zu…, Code und Codeblock.
    • Listenpunkt einrücken und Listenpunkt ausrücken.
    • Tabelle.

    Die Tasten, die keinen Platz finden, kommen in das ⋮ am Ende der Leiste, Weitere Formate, das sich am Finger öffnet. Fett, kursiv, durchgestrichen und Code wirken auf die Auswahl oder, wenn nichts ausgewählt ist, auf das Wort am Cursor; die Zeilenformate wirken auf jede Zeile, die die Auswahl berührt. Eine Taste ist hervorgehoben, solange der Cursor in ihrem Format steht. Ein zweites Tippen nimmt das Format wieder weg, außer bei Link, das wieder nach der Adresse fragt, und Tabelle, das in die Tabelle geht; Listenpunkt einrücken und Listenpunkt ausrücken bewegen den Punkt jeweils in eine Richtung.

    Mit In zwei Zeilen schreiben, in den Einstellungen unter „Schreiben“ und voreingestellt, zeigt die obere Zeile den Text formatiert, ohne seine Markdown-Zeichen, und die Zeile über der Tastatur das Markdown der Zeile mit dem Cursor, mit ◀ und ▶, um den Cursor zu bewegen. Ist es aus, zeigt das Feld die Zeichen gedämpft. Die Schnellnotiz schreibt immer in einer Zeile.

    Markdown tippen. Ein als Markdown getipptes Format wirkt schon beim Tippen:

    • Am Anfang einer Zeile, gefolgt von einem Leerzeichen: # für eine große Überschrift, ## für eine kleine, -, * oder + für einen Aufzählungspunkt, 1. für einen nummerierten Punkt und > für ein Zitat.
    • Innerhalb einer Zeile: **fett**, *kursiv* oder _kursiv_, ~~durchgestrichen~~, `Code` und [Text](Adresse).
    • Auf einer eigenen Zeile: ``` oder ~~~ beginnt einen Codeblock, und derselbe Zaun auf einer späteren Zeile beendet ihn; das Tippen des schließenden Zauns macht einen unformatierten Text formatiert.

    Jeder Zeilenumbruch bleibt einer, sodass untereinander getippte Zeilen getrennt bleiben. Ein Punkt, der um zwei Leerzeichen oder mehr eingerückt ist, steht eine Ebene weiter innen; tiefere Punkte erscheinen eine Ebene weiter innen. Aufeinanderfolgende nummerierte Punkte zählen weiter, sodass 1. auf jeder Zeile 1, 2, 3 zeigt. Tiefere Überschriften (###), Bilder und anderes Markdown erscheinen so, wie sie geschrieben sind.

    Auf einem Erfassungsbildschirm ohne Formatleiste wird ein Text, der mit Markdown getippt oder eingefügt wird, als formatierter Text gespeichert.

    Codeblöcke.

    Ein Codeblock sind die Zeilen zwischen zwei Zäunen aus drei Backticks, ```, oder drei Tilden, ~~~, jeder Zaun auf einer eigenen Zeile. Er erscheint in einer Schrift mit fester Breite auf grauem Grund, seine Zeilen genau so, wie sie geschrieben sind: Nichts darin ist ein Format, eine Tabelle, ein #Wort oder ein Statuskästchen. Ein Wort nach dem öffnenden Zaun, etwa ```bash, nennt die Sprache; es bleibt im Text, erscheint aber nicht. Ein Block endet erst an einem Zaun aus demselben Zeichen, der mindestens so lang ist wie der öffnende, sodass in einem mit vier Backticks begonnenen Block eine Zeile aus drei eine Zeile des Blocks ist. Ohne schließenden Zaun reicht der Block bis zum Ende des Texts.

    Codeblock in der Formatleiste setzt die Zeilen, die die Auswahl berührt, in einen Block, an einer leeren Zeile einen leeren; in einem Block nimmt es dessen Zäune weg. Seine Zäune sind länger als jede Folge von Backticks darin. Auf einer kompakten Karte zeigt ein Codeblock seine Zeilen ohne die Zäune.

    Links.

    Link fragt nach der „Web- oder E-Mail-Adresse“, eine vorhandene schon eingetragen; Link setzen legt sie auf die Auswahl oder das Wort am Cursor. Leer gelassen, entfernt sie den Link. Eine Adresse ohne „https://“ gilt als Webadresse, oder als E-Mail-Adresse, wenn sie ein „@“ und keinen „/“ enthält. Ein Tippen auf einen Link auf einer Karte öffnet ihn im Browser oder in der Mail-App. Nur Web- und E-Mail-Adressen und die eigenen Links der App öffnen sich; jeder andere Link, der auch von einer anderen Person in einem geteilten Bereich kommen kann, bleibt Text.

    Link zu… verlinkt einen Ort in der App: Wähl eine Notiz, einen Bereich oder ein Thema oder eine Seite wie die Agenda, Unsortiert, die Einstellungen oder einen ihrer Abschnitte, Alle Routinen und Erinnerungen, Sicherungen, Synchronisieren, das Profil, die Frösche, Neue Einheit oder die Anleitung; die Suche über der Liste findet sie. Der Link kommt auf die Auswahl oder das Wort am Cursor, sonst mit dem Namen des Ziels hinein. Ein Tippen darauf öffnet den Ort ohne Rückfrage, auf jedem Gerät; wo das Ziel nicht zu sehen ist, etwa eine Notiz im Papierkorb oder eine, die nie hierher synchronisiert wurde, sagt er „Hier nicht verfügbar“. Andere Markdown-Apps zeigen seine Wörter. Seine Adresse beginnt mit oldbrainfix://, etwa oldbrainfix://settings/backups.

    Ein Link auf eine Datei des geteilten Ordners, etwa oldbrainfix://file/Scans/steuer.pdf, öffnet sie mit der App, die Telefon oder Computer dafür haben, nach einer Frage, die die Datei und diese App nennt. Dateien außerhalb des geteilten Ordners (auf dem Desktop des synchronisierten Ordners) öffnen sich nie, und die Datei wird nicht in die App kopiert. Auf dem iPhone öffnen sich Dateilinks noch nicht.

    Eine Webadresse in einem Text, unformatiert oder formatiert, die mit „http://“ oder „https://“ beginnt, ist ebenfalls ein Link: Ein Tippen darauf öffnet sie im Browser, und ein Tippen daneben oder langes Drücken bewirkt, was es auf der Karte bewirkt. Satzzeichen direkt danach, etwa ein Punkt, ein Komma oder eine schließende Klammer, gehören nicht dazu; „www.“ allein ist kein Link. Eine Adresse in Code, einem Codeblock, einem Code-Text oder einem Link bleibt, wie sie geschrieben ist. Der Text selbst wird nicht verändert.

    Auf dem Desktop.

    • Die Formatleiste sitzt über dem Textfeld des Notiz-Dialogs, mit denselben Tasten; jede zeigt ihren Namen als Tooltip. Tasten, die keinen Platz finden, kommen in eine weitere Zeile. Strg+B und Strg+I sind beim Tippen fett und kursiv.
    • Ein Rechtsklick auf Wörter, die in einem formatierten Text ausgewählt sind, bietet für sie die Tasten der Formatleiste Fett, Kursiv, Code, Link und Codeblock an, unter Ausschneiden, Kopieren, Einfügen und Alles auswählen.
    • Ein formatierter Text erscheint so, wie er sich liest; ein Klick darauf bearbeitet sein Markdown, die Zeichen gedämpft. Das Feld zu verlassen oder Strg+Enter speichert ihn.
    • Eine Markdown-Aufgabe wie - [ ] Milch, getippt in der Schnellnotiz oder in Zur Notiz hinzufügen, wird beim Speichern des Textes zu einem Statuskästchen; im Notiz-Dialog, sobald das Leerzeichen nach ] getippt ist.
    • Zur Notiz hinzufügen hat die Formatleiste ebenfalls, ohne ☐, das nur der Text der Notiz einfügt; eine Tabelle darin wird im Feld bearbeitet wie im Notiz-Editor, und vor Zur Notiz hinzufügen wird nichts gespeichert.
    • Link öffnet einen Dialog mit demselben Feld; Enter oder Link setzen übernimmt es. Ein Klick auf einen Link öffnet ihn im Browser oder im Mailprogramm; die Maus darüber zeigt seine Adresse. Eine Webadresse in einem Text öffnet sich ebenfalls mit einem Klick.
    • Link zu…, neben Link, öffnet dieselbe Auswahl mit ihrer Suche; ein Klick auf ein Ziel setzt den Link. Ein Klick auf einen App-Link öffnet seinen Ort im Fenster, die Einstellungen an ihrem Abschnitt, eine Seite der Anleitung im Browser.

    Ein Skript als Code behalten

    Zeige den ganzen Text einer Notiz genau so, wie er geschrieben ist, etwa ein Skript.

  • Drücke lange auf die Karte der Notiz.
  • Tippe die Plakette Textformat.
  • Tippe Code.
    •
  • Doppelklicke die Karte der Notiz.
  • Klicke die Plakette Textformat.
  • Klicke Code.
    •

    Der ganze Text einer einfachen Notiz kann Code sein, etwa ein Skript: Er erscheint genau so, wie er geschrieben ist, in einer Schrift mit fester Breite auf grauem Grund, ohne seine Zeilen umzubrechen. Nichts darin ist ein Format, eine Tabelle, ein #Wort oder ein Statuskästchen. Im Notiz-Editor lässt sich eine lange Zeile mit dem Finger seitwärts schieben; auf einer Karte wird sie am Rand abgeschnitten, und der Editor zeigt sie ganz.

    • Die Plakette Textformat im Notiz-Editor zeigt das Format des Texts und wechselt es zwischen Unformatierter Text, Formatierter Text und Code. Ein formatierter Text kann Code werden, sein Markdown bleibt, wie es geschrieben ist, aber nicht direkt wieder unformatiert; ein Code-Text kann unformatiert oder formatiert werden. Die Plakette erscheint bei einer einfachen Notiz.
    • Sieht ein Text, der in den Text der Notiz eingefügt wird, wie ein Skript oder Code aus, sagt der Editor unter dem Text „Das sieht nach Code aus.“ mit Als Code behalten; das Kreuz lässt das Einfügen, wie es ist. Ein solches Einfügen formatiert den Text nicht. Ein Text sieht wie Code aus, wenn er mit #!/ beginnt oder wenn mindestens die Hälfte seiner drei oder mehr Zeilen auf ;, { oder } endet, mit } beginnt oder mit einem Tab oder vier Leerzeichen eingerückt ist, ohne einen Listenpunkt zu beginnen. Das Erfassen fragt nie.
    • Ein Code-Text hat keine Formatleiste und kein ☐. Sein ☐ bleibt ein Zeichen; ein Statuskästchen eines Texts, der Code wird, behält den Zustand, den es zeigt, als sein Zeichen.
    • Die Suche findet die Wörter eines Code-Texts, wie sie geschrieben sind. Teilen und Text kopieren geben ihn, wie er geschrieben ist.
    • Eine Notiz mit Code-Text ist keine Checkliste, Einkaufsliste, Strichliste oder Einheit; ihre Plakette Art zeigt die Art nur, bis das Textformat zurückgestellt ist.
    • Der Verlauf der Notiz nennt jede Änderung des Textformats.

    Auf dem Desktop steht die Plakette Textformat bei den Plaketten des Notiz-Dialogs und öffnet einen Dialog mit den drei Möglichkeiten. Ein Code-Text lässt sich mit Umschalt und dem Mausrad oder seiner Bildlaufleiste seitwärts schieben; „Als Code behalten“ erscheint nach einem Einfügen, das wie Code aussieht, unter dem Text.

    Eine Tabelle in eine Notiz setzen

    Halte Zeilen und Spalten, etwa Zählerstände, im Text einer Notiz fest.

  • Drücke lange auf die Karte der Notiz.
  • Tippe dorthin, wo die Tabelle hin soll.
  • Tippe Tabelle in der Formatleiste.
  • Schreibe in jede Zelle; ↵ geht zur Zelle darunter.
  • Tippe Speichern.
    •
  • Doppelklicke die Karte der Notiz.
  • Klicke dorthin, wo die Tabelle hin soll.
  • Klicke Tabelle über dem Text.
  • Schreibe in jede Zelle; Tab geht zur nächsten.
  • Klicke Speichern.
    •

    Im Notiz-Editor wird eine Tabelle direkt im Text bearbeitet, ihre Reihen nummeriert und ihre Spalten mit Buchstaben, auch eingefügte Markdown-Tabellen. Tabelle in der Formatleiste setzt eine neue Tabelle an den Cursor, zwei leere Spalten mit einer Kopfreihe und einer weiteren Reihe, auf eigenen Zeilen, und bearbeitet ihre erste Zelle.

    • Ein Tippen oder Klick auf eine Zelle bearbeitet sie an ihrem Platz. Tab und Umschalt+Tab gehen Reihe für Reihe zur nächsten und zur vorigen Zelle, ↵ zur Zelle darunter, und die Pfeiltasten am Rand einer Zelle zur Zelle daneben. Hinter der ersten oder der letzten Zelle geht der Cursor in den Text vor oder nach der Tabelle, und die Pfeiltasten (auf dem Handy auch ◀ und ▶) gehen aus dem Text in sie hinein.
    • Während eine Zelle bearbeitet wird, bietet die Formatleiste ☐, fett, kursiv, durchgestrichen, Link und Code für ihre Wörter. Eine Zelle hält eine Zeile.
    • + unter der letzten Reihe und neben der letzten Spalte fügt eine Reihe oder eine Spalte hinzu.
    • Ein Tippen oder Klick auf die Nummer einer Reihe öffnet Zeile darüber einfügen, Zeile darunter einfügen, Nach oben, Nach unten und Zeile löschen; der Buchstabe einer Spalte öffnet Spalte links einfügen, Spalte rechts einfügen, Nach links, Nach rechts, Spalte löschen, Linksbündig, Zentriert und Rechtsbündig, und bei Spalte A den Schalter Erste Spalte als Überschriften.
    • Eine Reihe oder Spalte zu löschen, die Wörter enthält, fragt einmal nach, „Diese Zeile löschen?“ oder „Diese Spalte löschen?“: „Die Wörter in ihren Zellen werden aus der Notiz gelöscht.“ Die letzte Reihe oder Spalte zu löschen, löscht die Tabelle und fragt „Die Tabelle löschen?“.
    • Als Zeilen zeigen zeigt die Markdown-Zeilen der Tabelle, um sie als Text zu bearbeiten; Als Tabelle zeigen, ein Cursor, der die Zeilen verlässt, oder das Verlassen des Felds zeigt wieder die Tabelle.

    Für den Text um sie herum ist eine Tabelle ein Block: Was direkt vor ihr getippt wird, kommt auf eine eigene Zeile, und was direkt nach ihr getippt wird, kommt unter sie, mit einer Leerzeile dazwischen. Die Rücktaste direkt nach einer Tabelle oder das Löschen einer Auswahl, die eine enthält, löscht die ganze Tabelle und fragt vorher nach, solange ihre Zellen Wörter enthalten. Auf dem Handy bewegt sich eine Tabelle, die breiter als das Feld ist, seitwärts, wenn ein Finger über sie zieht, und die Zeile über der Tastatur ist verborgen, während eine Zelle bearbeitet wird.

    Tabellen werden als GFM-Tabellen geschrieben: Jede Änderung schreibt die ganze Tabelle neu, jede Reihe als | a | b |, und lässt die Wörter in ihren Zellen, wie sie waren. Markdown kennt keine Spaltenbreiten: Am Desktop lässt sich der Rand einer Spalte ziehen, um sie breiter oder schmaler zu machen, und diese Breite wird nicht behalten. Eine Zeile, die direkt unter das Markdown einer Tabelle getippt wird, ohne Leerzeile dazwischen, wird eine Reihe von ihr.

    Auf einer Karte und wo du die Notiz nur lesen darfst, erscheint eine Tabelle auf die Breite verkleinert, ihre Kopfreihe fett; ein Tippen oder Klick darauf öffnet sie im Vollbild, um sie von der Karte aus zu bearbeiten oder nur zu lesen. Im Vollbild bleibt die Kopfreihe sichtbar, während die Reihen rollen, und ebenso die erste Spalte, solange sie Überschriften enthält; auf dem Handy bewegt sich eine Tabelle, die breiter als der Bildschirm ist, seitwärts, wenn ein Finger über ihre Zellen zieht, oder über Tabelle seitlich verschieben. Am Desktop verlassen Alt+Links, die Zurück-Taste der Maus, Esc oder der Pfeil oben sie.

    Ein Statuskästchen im Text abhaken

    Markiere einen Punkt in einem Text als erledigt oder gescheitert, etwa „✅ v2 unterstützt“.

  • Tippe ☐ in den Text, oder tippe ☐ in der Formatleiste.
  • Tippe Zurück.
  • Tippe das ☐ auf der Karte der Notiz.
  • Tippe Abhaken, Als gescheitert markieren oder Wieder öffnen.
  • Tippe das Statuskästchen noch einmal, dann Verlauf.
    •
  • Tippe ☐ in den Text, oder klicke ☐ über dem Text.
  • Klicke neben den Text.
  • Klicke das ☐ auf der Karte der Notiz.
  • Klicke Abhaken, Als gescheitert markieren oder Wieder öffnen.
  • Klicke das Statuskästchen noch einmal, dann Verlauf.
    •

    Ein ☐, ✅ oder ❌ irgendwo im Text einer Notiz oder eines Abschnitts ist ein Statuskästchen: offen, abgehakt oder gescheitert, etwa „✅ v2 beim Kunden unterstützt“. Es wird beim Speichern des Textes zu einem Statuskästchen, und das Zeichen, mit dem es geschrieben wurde, ist der Zustand, mit dem es beginnt. Ein Tippen darauf öffnet am Finger ein Menü mit Abhaken, Als gescheitert markieren und Wieder öffnen, ohne den aktuellen Zustand. Die Wahl wird neben dem Text gespeichert, mit Person und Zeitpunkt, und auf jedes Gerät synchronisiert; der Text selbst bleibt, wie er ist.

    • Ein Statuskästchen kann mitten in einem Wort oder einer Zeile stehen, in einem Listenpunkt, einem Zitat, den Wörtern eines Links und einer Tabellenzelle. In Code im Text, in einem Codeblock, in der Adresse eines Links oder in einer Webadresse zählt es nicht; ebenso wenig andere Kästchen und Haken wie ☑ oder ✓.
    • Statuskästchen werden auf der Karte der Notiz, in ihren Abschnitten, im Notiz-Editor und in einer Tabelle im Vollbild abgehakt. Ein Statuskästchen, das gerade getippt wird, lässt sich abhaken, sobald der Text gespeichert ist.
    • ☐ in der Formatleiste setzt ☐ am Cursor ein, auch mitten in einem Wort.
    • In einem formatierten Text wird ein Listenpunkt, der als Markdown-Aufgabe geschrieben ist, etwa - [ ] Milch oder 1. [x] Brot, zu einem Statuskästchen: [ ] wird ☐, [x] oder [X] wird ✅. Das geschieht, sobald das Leerzeichen nach ] getippt ist, wenn eine solche Liste eingefügt wird und wenn eine Markdown-Datei importiert wird. In Code, einem Codeblock, einem Code-Text oder einem unformatierten Text bleibt es, wie es geschrieben ist.
    • Jedes Statuskästchen trägt eine Kennung, die nie zu sehen ist. Der Cursor springt über ein Statuskästchen wie über ein Zeichen; wird sein Zeichen gelöscht, ist das Statuskästchen gelöscht.
    • Ticks zeigen, im ⋮ der Karte der Notiz und als Plakette im Notiz-Editor, solange die Notiz oder ein Abschnitt ein Statuskästchen enthält, zeigt nach jedem abgehakten Statuskästchen klein und grau, wer es zuletzt wann geändert hat, etwa „Ann, Di. 14:02“, oder „Du“ bei deinen eigenen; eine ältere Änderung zeigt ihr Datum. Das gilt für diese Notiz auf diesem Gerät.
    • Sobald ein Statuskästchen geändert wurde, hat sein Menü auch Verlauf: jede Änderung, die älteste zuerst, mit Zustand, Person und Zeitpunkt.
    • In einem geteilten Bereich ändert jeder mit einer Rolle dort jedes Statuskästchen jeder Notiz und jedes Abschnitts. Statuskästchen hinzufügen, verschieben und löschen ist eine Änderung des Textes und bleibt der Person, die die Notiz geschrieben hat, und den Verwaltern. Eine Notiz im Papierkorb wird nicht abgehakt; wo du nicht abhaken darfst, hat das Menü eines schon geänderten Statuskästchens nur Verlauf.
    • Kopien, Weitergaben, Markdown-Dateien und gesendete Notizen zeigen jedes Statuskästchen in seinem jetzigen Zustand. Als Text kopieren, Teilen und Als Markdown speichern schreiben einen Listenpunkt eines formatierten Textes, der mit einem Statuskästchen beginnt, als Markdown-Aufgabe, sodass andere Markdown-Apps ein Ankreuzfeld zeigen: ☐ als - [ ], ✅ als - [x] und ❌ als - [x] mit dem Rest des Punkts durchgestrichen. Die formatierte Kopie daneben zeigt die Statuskästchen, wie sie sind.

    Auf dem Desktop öffnet ein Klick auf ein Statuskästchen sein Menü darunter, auch im Feld, das gerade bearbeitet wird: ☐ Wieder öffnen, ✅ Abhaken und ❌ Als gescheitert markieren, ohne den aktuellen Zustand, und, sobald es einmal geändert wurde, Verlauf. Im Feld, das gerade bearbeitet wird, springen die Pfeiltasten über ein Statuskästchen wie über ein Zeichen, und die Rücktaste dahinter oder Entf davor entfernt es mit seiner Kennung. Ticks zeigen steht im ⋮ der Karte und ist im Notiz-Dialog eine Plakette mit einem Schalter.

    Notizen an einem #Wort finden

    Markiere Notizen mit einem Wort wie #Garten und finde sie alle wieder.

  • Tippe # und ein Wort in den Text einer Notiz, etwa #Garten.
  • Tippe das #Wort auf einer Karte.
    •
  • Tippe # und ein Wort in den Text einer Notiz, etwa #Garten.
  • Klicke das #Wort auf einer Karte.
    •

    Ein Wort mit „#“ davor, etwa „#Garten“, ist ein #Wort und erscheint in der Akzentfarbe, auf Karten, in Abschnitten und im Editor. Ein Tippen darauf auf einer Karte, in einem Abschnitt oder in einer Tabelle öffnet die Suche in allen Notizen nach dem Wort, so wie es geschrieben ist. Für ein #Wort wird nichts gespeichert; es ist ein Wort des Texts, und die Liste der #Wörter zeigt sie alle (siehe „Deine #Wörter durchstöbern“). Das #Wort in die Suche zu tippen, findet dasselbe.

    • Ein #Wort besteht aus Buchstaben, Ziffern, „_“ und „-“ und enthält mindestens einen Buchstaben: „#to-do“ und „#v2“ zählen, „#126“ ist eine Zahl.
    • Ein „/“ verschachtelt ein #Wort: „#leben/gesundheit/rücken“ ist ein #Wort, unter „#leben/gesundheit“ und „#leben“. Die Suche nach „#leben“ findet es auch.
    • „# Titel“ mit Leerzeichen, „C#“ und das „#“ in einer Webadresse zählen nicht. In einem formatierten Text zählt auch ein „#Wort“ in Code, in einem Codeblock oder in der Adresse eines Links nicht, ebenso wenig eines in einem Code-Text.
    • Die Suche nach „#Garten“ findet jede Notiz, die es in beliebiger Groß- und Kleinschreibung enthält, auch „#Gartenarbeit“, das damit beginnt, aber nicht das Wort „Garten“ ohne „#“.

    Auf dem Desktop schließt ein Klick auf ein #Wort den Notiz-Dialog und durchsucht alle Notizen, wie auf dem Handy; im Feld, das gerade bearbeitet wird, setzt er den Cursor.

  • Tippe ein #Wort, um danach zu suchen.

  • Drücke Strg+F.
  • Tippe # und den Anfang eines #Worts, etwa #leben.
    •

    Die Liste der #Wörter zeigt die #Wörter aller Notizen und ihrer Abschnitte, die oberste Ebene so wie geschrieben („#leben“), jede Ebene darunter mit ihrem eigenen Wort („gesundheit“), eingerückt, mit der Anzahl der Notizen, die das #Wort oder eines darunter tragen. Zuerst zeigt nur die oberste Ebene; der Pfeil neben einem #Wort klappt die Ebenen darunter auf. Ein Tippen auf ein #Wort führt zurück in die Liste der Bereiche und sucht dort danach. Ein #Wort, das verschieden geschrieben ist („#Leben“, „#leben“), zeigt sich so, wie die meisten seiner Notizen es schreiben.

    Wenn du „#“ in die Suche der Liste der Bereiche tippst, zeigen sich die #Wörter, die mit dem Getippten beginnen, als Knöpfe unter dem Feld, höchstens zwölf; ein Tippen setzt eines ein, sodass du ein #Wort findest, ohne seine genaue Schreibweise zu kennen. Solange ein gesperrter Bereich zu ist, fehlen die #Wörter seiner Notizen unter #Wörter und in diesen Knöpfen, wie seine Notizen in jeder Liste fehlen.

    Die Desktop-App hat noch keine Liste der #Wörter. Ihre Suche nach „#leben“ findet jede Notiz mit einem #Wort darunter, wie auf dem Handy.

    Die Worte einer Sprachaufnahme bekommen

    Lass die App aufschreiben, was eine Sprachaufnahme sagt, als ihr Transkript.

  • Tippe dein Profilbild, dann Einstellungen.
  • Tippe Sprachmodell.
  • Tippe Basis, 148 MB.
  • Nimm eine Sprachnotiz auf.
    •
  • Klicke Bearbeiten ▸ Einstellungen ….
  • Klicke Basis, 148 MB unter „Sprachmodell“.
  • Nimm eine Sprachnotiz auf.
    •

    Eine Sprachaufnahme bekommt ein Transkript: die darin erkannten Wörter, neben der Aufnahme aufbewahrt. Whisper schreibt es auf dem Gerät, auf Deutsch oder Englisch, je nachdem, wonach die Aufnahme eher klingt, im Hintergrund und eine Aufnahme nach der anderen, sobald die Notiz gespeichert ist; Aufnahmen, die vor dem Sprachmodell erfasst wurden, folgen. Solange es läuft, steht „Wird transkribiert …“ unter der Aufnahme; eine Aufnahme ohne Sprache zeigt „Keine Worte erkannt.“. Die Aufnahme bleibt immer erhalten.

    Whisper bekommt die Namen deiner Bereiche und Themen vorgegeben, bei deutscher Sprache auch die englischen Wörter, die im Deutschen üblich sind, und die Wörter der App wie Unsortiert, Routine und Agenda, damit sie so geschrieben werden, wie man sie schreibt. Wo Whisper diese Vorgabe oder eine Folge von drei oder mehr dieser Namen nur wiederholt, wird die Wiederholung aus dem Transkript genommen.

    Die Sprachmodelle.

    Transkripte brauchen ein Sprachmodell, das einmal heruntergeladen wird. Das Handy bietet es nach dem ersten Start an (siehe Erste Schritte); Einstellungen, Sprachmodell bietet es auf dem Handy und dem Desktop jederzeit an. Unter „Modell“:

    • Basis, 148 MB: schneller und genug für Deutsch oder Englisch allein.
    • Klein, 488 MB: besser mit englischen Wörtern in deutscher Sprache, aber langsamer, und es braucht mehr Arbeitsspeicher.

    Ein Modell zu wählen, lädt es herunter, mit Fortschritt und Abbrechen. Nur das gewählte Modell wird behalten: Das vorige wird gelöscht, sobald das neue bereit ist. Jeder Download kommt nur aus der eigenen Veröffentlichung von Old Brain Fix auf GitHub und wird vor der Verwendung gegen eine feste Prüfsumme geprüft; ein abgebrochener oder nicht passender Download behält nichts und sagt das. Eigene Datei verwenden nimmt die mehrsprachige ggml-base.bin oder ggml-small.bin von whisper.cpp vom Gerät, erkannt an ihrer Prüfsumme, wie auch immer die Datei heißt; jede andere Datei wird abgelehnt.

    Auf dem Desktop ist das Sprachmodell eine Karte im Dialog Einstellungen, nach „Schnellnotiz“, mit denselben Möglichkeiten; Transkripte funktionieren ebenso, solange die App läuft.

    Auf dem iPhone wird eine Sprachnachricht, die auf einem Android-Handy als Ogg-Datei in die App geteilt wurde, wie WhatsApp sie schickt, weder abgespielt noch transkribiert: iOS liest kein Ogg. Aufnahmen aus Old Brain Fix spielen auf jedem Gerät.

    Den Text eines Fotos bekommen

    Lass die App den Text auf einem Foto lesen, etwa einem Kassenbon, als seinen Fototext.

  • Tippe + auf der Agenda.
  • Tippe Foto oder Galerie.
  • Mach oder wähle das Foto.
  • Tippe 10 Min., 30 Min. oder 1 Std.
  • Lies den Fototext unter dem Foto auf seiner Karte.
    •
  • Drücke Strg+N oder klicke Datei ▸ Neue Notiz.
  • Klicke Einfügen oder Aus Datei… für das Foto.
  • Klicke 10 Min., 30 Min. oder 1 Std.
  • Doppelklicke die Karte der Notiz.
  • Lies den Fototext unter dem Foto.
    •

    Ein Foto oder Bild bekommt einen Fototext: den darin erkannten Text, neben dem Foto aufbewahrt. RustO liest ihn auf dem Gerät mit den Modellen PP-OCRv6 Tiny von PaddleOCR, die Teil der App sind, sodass nichts heruntergeladen wird und nichts das Gerät verlässt. Es liest deutsche Buchstaben (ä, ö, ü, ß) und € und behält die Zeilen so, wie sie auf dem Foto liegen, sodass ein Preis auf der Zeile seines Artikels bleibt. Bei einer stark gewölbten Seite können Zeilen fehlen. Fotos werden im Hintergrund gelesen, eins nach dem anderen, sobald die Notiz gespeichert ist; das Erfassen wartet nie darauf.

    In der Detailansicht einer Karte stehen Transkripte und Fototexte gedämpft unter dem Wort „Transkript“ oder „Fototext“. Die Kompaktansicht einer Notiz ohne Worte zeigt die ersten drei Zeilen ihrer Transkripte und der Fototexte entfernter Fotos; ein Foto, das noch da ist, erscheint als kleines Bild.

    Auf dem Desktop funktionieren Fototexte ebenso, solange die App läuft; der Notiz-Dialog zeigt jeden unter seinem Foto.

    Eine Datei an eine Notiz hängen

    Bewahre einen Brief, einen Vertrag oder jede andere Datei bei der Notiz auf, zu der sie gehört.

  • Tippe + auf der Agenda.
  • Tippe Datei.
  • Wähle eine oder mehrere Dateien.
  • Tippe 10 Min., 30 Min. oder 1 Std.
  • Tippe den Anhang auf seiner Karte, um ihn zu öffnen.
    •
  • Hänge die Datei auf dem Handy an.
  • Synchronisiere den Computer mit dem Handy.
  • Drücke Strg+F.
  • Tippe ein Wort aus dem Text der Datei.
    •

    Jede Datei lässt sich anhängen: ein PDF, ein Word-Dokument, eine Tabelle, ein .zip. Sie bleibt, wie sie ist, mit Name, Art und Größe, auf all deinen Geräten und bei allen, mit denen du den Bereich der Notiz teilst. Außer über Datei beim Erfassen und im Fächer von + kommt ein Anhang herein, wenn du eine Datei aus einer anderen App mit Old Brain Fix teilst, und über Datei anhängen in der Leiste des Notiz-Editors. Eine Datei, die größer als 256 MB ist, wird nicht angehängt, und die App sagt es oben. Eine Notiz, die nur aus einer Datei gemacht wurde, zeigt die Datei als ihre Karte und heißt nach ihr, auch in Alarmen. Ein Tippen auf einen Anhang öffnet ihn mit der App des Handys, die diese Art öffnet; einer, der noch nicht auf das Handy synchronisiert ist oder den keine App öffnet, wird oben gemeldet.

    Der Text einer Datei wird gelesen, wo ihr Format es erlaubt: der eigene Text eines PDFs und, mit derselben Texterkennung wie bei Fotos, seine gescannten Seiten; .docx-, .odt-, .xlsx- und .ods-Dateien; reiner Text und Markdown. Dieser Anhangtext steht abgeblendet unter dem Anhang, unter dem Wort „Anhangtext“, und die Suche findet ihn und den Namen der Datei. Das Handy liest ein PDF bis zehn Seiten und andere Dateien bis 10 MB selbst, im Hintergrund. Ein längeres PDF oder eine größere Datei bleibt deinem Computer überlassen: Bis er sie gelesen hat und der Text zurück synchronisiert ist, zeigt das Handy „Der Text folgt vom Computer.“ Andere Dateien, etwa ein .zip, haben keinen Text.

    Im Notiz-Editor unter jedem Anhang: Notiztext ersetzen und An Notiztext anhängen übernehmen seinen Text, Erkannten Text entfernen entfernt den Text (die Meldung oben holt ihn zurück), Text erneut lesen liest ihn neu, und Anhang entfernen, Text behalten fragt einmal und entfernt die Datei von all deinen Geräten, während ihr Text bleibt. Das ⋮ der Karte bietet das Letzte auch an.

    Die Desktop-App zeigt Anhänge noch nicht; ihre Suche findet ihre Namen und Texte schon.

    Ein Transkript oder einen Fototext übernehmen oder entfernen

    Nimm ein Transkript oder einen Fototext in den Text der Notiz, oder entferne ihn.

  • Drücke lange auf die Karte der Notiz.
  • Tippe Notiztext ersetzen oder An Notiztext anhängen.
  • Tippe stattdessen Erkannten Text entfernen.
    •
  • Doppelklicke die Karte der Notiz.
  • Klicke Notiztext ersetzen oder An Notiztext anhängen.
  • Klicke stattdessen Erkannten Text entfernen.
    •

    Ein Transkript oder Fototext wird nur von der App geschrieben; er lässt sich nicht bearbeiten. Im Notiz-Editor steht unter jedem Transkript und Fototext, auch denen eines Abschnitts einer zusammengeführten Notiz:

    • Notiztext ersetzen macht ihn zum Text; An Notiztext anhängen fügt ihn auf einer eigenen Zeile nach dem Text an. Unter dem Transkript oder Fototext eines Abschnitts ändern sie den Text dieses Abschnitts. Der Text wird dann wie gewohnt bearbeitet. In einen formatierten Text geht er als einfacher Text, so geschrieben, dass er sich selbst liest. Beide erscheinen, solange der erkannte Text Worte hat und der Text geändert werden darf.
    • Erkannten Text entfernen fragt nichts. Auf dem Handy holt die Meldung oben, „Transkript entfernt“ oder „Fototext entfernt“, den Text mit einem Tippen zurück, auf dem Desktop Strg+Z oder Bearbeiten ▸ Rückgängig. Dann findet die Suche den Text auf keinem deiner Geräte mehr, und Aufnahme oder Foto bleiben, sodass sich der Text daraus neu erkennen lässt. Der Text einer entfernten Aufnahme oder eines entfernten Fotos lässt sich nicht entfernen; er ist alles, was davon bleibt.
    • Erneut transkribieren und Text erneut lesen erzeugen den Text neu aus der Datei, anstelle des vorigen oder eines entfernten. Sie erscheinen, solange die Datei auf diesem Gerät ist und das Sprachmodell oder RustO dort läuft. Kommt nichts dabei heraus, sagt eine Meldung oben das, und ein Tippen darauf nennt den Grund; die Datei bleibt.

    Aufnahme entfernen, Text behalten und Foto entfernen, Text behalten, im Editor und im ⋮ der Karte, tun das Umgekehrte für eine Aufnahme oder ein Foto mit Text: Sie fragen einmal nach („Diese Aufnahme entfernen und ihr Transkript behalten?“ oder „Dieses Foto entfernen und seinen Text behalten?“), dann verschwindet die Datei von all deinen Geräten und bei allen, mit denen du den Bereich der Notiz teilst, und der Text bleibt in der Notiz. Das ⋮ der Karte bietet sie für die eigenen Dateien der Notiz an, der Editor auch für die ihrer Abschnitte. In einem geteilten Bereich tut ein Mitglied all das nur bei seinen eigenen Notizen.

    Auf dem Desktop stehen all diese Tasten im Notiz-Dialog, unter jedem Foto und jeder Aufnahme; das ⋮ der Karte hat keine davon.

    Deine Notizen durchsuchen

    Finde Notizen an einem Wort in ihrem Text, ihren Transkripten, Fototexten und Listen.

  • Tippe Suchen und stöbern.
  • Tippe ein Wort in Alle Notizen durchsuchen.
    •
  • Drücke Strg+F.
  • Tippe ein Wort.
    •

    Der Notizbrowser hat auf jeder Ebene ein Suchfeld: „Alle Notizen durchsuchen“ in der Liste der Bereiche, „Diesen Bereich durchsuchen“ und „Dieses Thema durchsuchen“ darunter. Die Suche findet, was getippt wird, in beliebiger Groß- und Kleinschreibung, im Text einer Notiz und ihrer Abschnitte, in ihren Transkripten und Fototexten, in den Namen und Anhangtexten ihrer Anhänge, in den Textzeilen der Einträge ihrer Strichliste und in den Zeilen ihrer Checkliste oder Einkaufsliste. Ein formatierter Text wird so durchsucht, wie er sich liest: „fett“ findet „**fett**“, und die Markdown-Zeichen werden nirgends gefunden. Ein entferntes Transkript oder ein entfernter Fototext wird nicht mehr gefunden.

    Auf dem Desktop sitzt das Suchfeld über der Liste der Notizen: „Alle Notizen durchsuchen“ bei Alle Notizen, „In Unsortiert suchen“ bei Unsortiert, „Diesen Bereich durchsuchen“ bei einem Bereich, „Dieses Thema durchsuchen“ bei einem Thema und „Im Papierkorb suchen“ im Papierkorb, das auch seine Routinen, Erinnerungen und Frösche über ihre Notiz findet; die Agenda hat keines. Strg+F oder Bearbeiten ▸ Suchen setzt den Cursor hinein, in das von Alle Notizen, wo die gezeigte Liste keines hat. Pfeil runter im Feld geht zur ersten gefundenen Karte.
