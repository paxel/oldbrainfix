Old Brain Fix kommt auf Android aus dem F-Droid-Repository oder als APK, auf dem Computer über Homebrew, Scoop, das apt-Repository oder eine Datei der neuesten Version.

Android

  • F-Droid: das Repository https://paxel.github.io/fdroid/repo im F-Droid-Client hinzufügen und Old Brain Fix daraus installieren. Updates kommen über F-Droid.
  • APK: oldbrainfix-<version>-android-universal.apk aus der neuesten Version herunterladen und öffnen. Die APKs arm64-v8a und armeabi-v7a sind kleiner und passen nur auf Telefone mit diesem Prozessor.

iPhone

Old Brain Fix für das iPhone, ab iOS 26, gibt es vorerst für Testende, über Apples App TestFlight.

Linux

  • Homebrew: brew install paxel/tap/oldbrainfix. Die App einmal starten; sie trägt sich selbst ins Anwendungsmenü ein.
  • Debian, Ubuntu, apt-Repository: einmal das signierte Repository des Projekts und ihren Schlüssel mit sudo wget -qO /etc/apt/keyrings/oldbrainfix.asc https://paxel.github.io/oldbrainfix/apt/oldbrainfix.asc && echo "deb [signed-by=/etc/apt/keyrings/oldbrainfix.asc] https://paxel.github.io/oldbrainfix/apt stable main" | sudo tee /etc/apt/sources.list.d/oldbrainfix.list eintragen, dann mit sudo apt update && sudo apt install oldbrainfix installieren. Spätere Versionen kommen mit den Updates des Systems.
  • Debian, Ubuntu, einzelne Datei: die .deb für den Prozessor (x86_64 oder arm64) herunterladen und mit sudo apt install ./oldbrainfix-<version>-linux-x86_64.deb installieren.
  • Fedora, openSUSE: die .rpm für den Prozessor (x86_64 oder arm64) herunterladen und mit sudo dnf install ./oldbrainfix-<version>-linux-x86_64.rpm installieren, unter openSUSE mit sudo zypper install --allow-unsigned-rpm ./oldbrainfix-<version>-linux-x86_64.rpm.
  • AppImage: das .AppImage herunterladen, mit chmod +x ausführbar machen und starten.

Homebrew, die .deb, die .rpm und das AppImage brauchen Linux mit glibc 2.35 oder neuer, etwa Ubuntu 22.04, Debian 12 oder Fedora 36 und ihre späteren Versionen.

macOS

  • Homebrew: brew install --cask paxel/tap/oldbrainfix. Das --cask ist nötig; ohne nimmt Homebrew die gleichnamige Linux-Formel.
  • Disk-Image: die .dmg für den Mac herunterladen (arm64 für Apple Silicon, x86_64 für Intel) und Old Brain Fix in Programme ziehen.

Die App ist nicht mit einem Apple-Entwicklerzertifikat signiert. Beim ersten Start lehnt macOS sie ab: Systemeinstellungen, Datenschutz & Sicherheit öffnen und „Dennoch öffnen“ wählen.

Windows

  • Scoop: scoop bucket add paxel https://github.com/paxel/scoop-bucket, dann scoop install paxel/oldbrainfix.
  • Zip: oldbrainfix-<version>-windows-x86_64.zip herunterladen, entpacken und oldbrainfix.exe starten.

Updates

Homebrew (brew upgrade), Scoop (scoop update oldbrainfix) und F-Droid folgen neuen Versionen. Eine Datei von der Versionsseite wird durch die Datei der nächsten Version ersetzt.
