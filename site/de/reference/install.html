Old Brain Fix kommt auf Android aus dem F-Droid-Repository oder als APK, auf dem Computer über Homebrew, Scoop oder eine Datei der neuesten Version.

Android

  • F-Droid: das Repository https://paxel.github.io/fdroid/repo im F-Droid-Client hinzufügen und Old Brain Fix daraus installieren. Updates kommen über F-Droid.
  • APK: oldbrainfix-<version>-android-universal.apk aus der neuesten Version herunterladen und öffnen. Die APKs arm64-v8a und armeabi-v7a sind kleiner und passen nur auf Telefone mit diesem Prozessor.

Linux

  • Homebrew: brew install paxel/tap/oldbrainfix. Die App einmal starten; sie trägt sich selbst ins Anwendungsmenü ein.
  • Debian, Ubuntu: die .deb für den Prozessor (x86_64 oder arm64) herunterladen und mit sudo apt install ./oldbrainfix-<version>-linux-x86_64.deb installieren.
  • Flatpak: die .flatpak herunterladen und mit flatpak install --user ./oldbrainfix-<version>-linux-x86_64.flatpak installieren. Die Laufzeit kommt von Flathub.
  • AppImage: das .AppImage herunterladen, mit chmod +x ausführbar machen und starten.

macOS

  • Homebrew: brew install --cask paxel/tap/oldbrainfix. Das --cask ist nötig; ohne nimmt Homebrew die gleichnamige Linux-Formel.
  • Disk-Image: die .dmg für den Mac herunterladen (arm64 für Apple Silicon, x86_64 für Intel) und Old Brain Fix in Programme ziehen.

Die App ist nicht mit einem Apple-Entwicklerzertifikat signiert. Beim ersten Start lehnt macOS sie ab: Systemeinstellungen, Datenschutz & Sicherheit öffnen und „Dennoch öffnen“ wählen.

Windows

  • Scoop: scoop bucket add paxel https://github.com/paxel/scoop-bucket, dann scoop install paxel/oldbrainfix.
  • Zip: oldbrainfix-<version>-windows-x86_64.zip herunterladen, entpacken und oldbrainfix.exe starten.

Updates

Homebrew (brew upgrade), Scoop (scoop update oldbrainfix) und F-Droid folgen neuen Versionen. Eine Datei von der Versionsseite wird durch die Datei der nächsten Version ersetzt.
