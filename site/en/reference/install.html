Old Brain Fix is installed from the F-Droid repository or an APK on Android, and from Homebrew, Scoop or a file of the latest release on the desktop.

Android

  • F-Droid: add the repository https://paxel.github.io/fdroid/repo in your F-Droid client, then install Old Brain Fix from it. Updates arrive through F-Droid.
  • APK: download oldbrainfix-<version>-android-universal.apk from the latest release and open it. The arm64-v8a and armeabi-v7a APKs are smaller and fit only phones with that processor.

Linux

  • Homebrew: brew install paxel/tap/oldbrainfix. Start the app once; it adds itself to the application menu.
  • Debian, Ubuntu: download the .deb for your processor (x86_64 or arm64) and install it with sudo apt install ./oldbrainfix-<version>-linux-x86_64.deb.
  • Flatpak: download the .flatpak and install it with flatpak install --user ./oldbrainfix-<version>-linux-x86_64.flatpak. Its runtime comes from Flathub.
  • AppImage: download the .AppImage, make it executable with chmod +x and start it.

macOS

  • Homebrew: brew install --cask paxel/tap/oldbrainfix. The --cask is needed; without it Homebrew picks the Linux formula of the same name.
  • Disk image: download the .dmg for your Mac (arm64 for Apple silicon, x86_64 for Intel) and drag Old Brain Fix into Applications.

The app is not signed with an Apple Developer certificate. On the first start macOS refuses it: open System Settings, Privacy & Security, and choose Open Anyway.

Windows

  • Scoop: scoop bucket add paxel https://github.com/paxel/scoop-bucket, then scoop install paxel/oldbrainfix.
  • Zip: download oldbrainfix-<version>-windows-x86_64.zip, unpack it and start oldbrainfix.exe.

Updates

Homebrew (brew upgrade), Scoop (scoop update oldbrainfix) and F-Droid follow new releases. A file from the release page is replaced by the next release's file.
