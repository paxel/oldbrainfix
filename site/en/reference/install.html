Old Brain Fix is installed from the F-Droid repository or an APK on Android, and from Homebrew, Scoop, the apt repository or a file of the latest release on the desktop.

Android

  • F-Droid: add the repository https://paxel.github.io/fdroid/repo in your F-Droid client, then install Old Brain Fix from it. Updates arrive through F-Droid.
  • APK: download oldbrainfix-<version>-android-universal.apk from the latest release and open it. The arm64-v8a and armeabi-v7a APKs are smaller and fit only phones with that processor.

iPhone

Old Brain Fix for the iPhone, for iOS 26 and newer, is for testers for now, through Apple's TestFlight app.

Linux

  • Homebrew: brew install paxel/tap/oldbrainfix. Start the app once; it adds itself to the application menu.
  • Debian, Ubuntu, apt repository: add the project's signed repository and its key once with sudo wget -qO /etc/apt/keyrings/oldbrainfix.asc https://paxel.github.io/oldbrainfix/apt/oldbrainfix.asc && echo "deb [signed-by=/etc/apt/keyrings/oldbrainfix.asc] https://paxel.github.io/oldbrainfix/apt stable main" | sudo tee /etc/apt/sources.list.d/oldbrainfix.list, then install with sudo apt update && sudo apt install oldbrainfix. Later versions arrive with the system's updates.
  • Debian, Ubuntu, single file: download the .deb for your processor (x86_64 or arm64) and install it with sudo apt install ./oldbrainfix-<version>-linux-x86_64.deb.
  • Fedora, openSUSE: download the .rpm for your processor (x86_64 or arm64) and install it with sudo dnf install ./oldbrainfix-<version>-linux-x86_64.rpm, on openSUSE with sudo zypper install --allow-unsigned-rpm ./oldbrainfix-<version>-linux-x86_64.rpm.
  • AppImage: download the .AppImage, make it executable with chmod +x and start it.

Homebrew, the .deb, the .rpm and the AppImage need Linux with glibc 2.35 or newer, such as Ubuntu 22.04, Debian 12 or Fedora 36 and their later releases.

macOS

  • Homebrew: brew install --cask paxel/tap/oldbrainfix. The --cask is needed; without it Homebrew picks the Linux formula of the same name.
  • Disk image: download the .dmg for your Mac (arm64 for Apple silicon, x86_64 for Intel) and drag Old Brain Fix into Applications.

The app is not signed with an Apple Developer certificate. On the first start macOS refuses it: open System Settings, Privacy & Security, and choose Open Anyway.

Windows

  • Scoop: scoop bucket add paxel https://github.com/paxel/scoop-bucket, then scoop install paxel/oldbrainfix.
  • Zip: download oldbrainfix-<version>-windows-x86_64.zip, unpack it and start oldbrainfix.exe.

Updates

Homebrew (brew upgrade), Scoop (scoop update oldbrainfix) and F-Droid follow new releases. A file from the release page is replaced by the next release's file.
